O que é o 5 Minutos Para Mim

Uma jornada prática para começar a se incluir na própria rotina, cinco minutos de cada vez.

Tudo acontece em um aplicativo, feito para acompanhar você durante essa jornada.

A cada dia, você encontra uma prática curta para parar por alguns minutos, perceber como está e voltar a colocar você também dentro do seu dia.

Simples assim

  1. 1
    Um novo passo a cada dia

    Uma prática curta, pensada para caber no seu dia.

  2. 2
    Cerca de 5 minutos

    No momento que funcionar melhor para você.

  3. 3
    Um caminho possível

    Um passo de cada vez, para que se incluir na própria rotina deixe de ficar sempre para depois.

Para você que:

  • cuida de muita coisa e raramente entra na própria lista;
  • quer se incluir na rotina sem precisar reorganizar a vida inteira;
  • prefere começar pequeno a esperar o momento ideal.

Você não precisa esperar a rotina ficar mais leve para começar a se incluir nela.
